# hsblock-rs

Hierarchical Stochastic Block Model for graph community detection.

Rust library name: `hsblock` (`use hsblock::…`).

```toml
hsblock = { package = "hsblock-rs", version = "0.1" }
```

Depends on [`legume-numeric`](https://crates.io/crates/legume-numeric) for Leiden network types.
